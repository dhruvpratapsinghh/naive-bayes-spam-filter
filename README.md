# 📧 Email Spam Analyzer

A lightweight, interactive web application built with Python and Streamlit that analyzes email text and calculates a spam risk score.

*Note: Currently running a rule-based keyword detection engine. Upcoming versions will integrate a Naive Bayes Machine Learning model.*

## 🚀 Features
* **Interactive UI:** Built with Streamlit for instant feedback.
* **Keyword Detection:** Scans text against a database of known spam trigger words.
* **Risk Scoring:** Calculates a dynamic spam probability percentage based on trigger frequency.
* **Visual Status:** Provides clear Safe, Suspicious, or High Risk status indicators.

## 🛠️ Tech Stack
* **Language:** Python
* **Frontend Framework:** Streamlit
